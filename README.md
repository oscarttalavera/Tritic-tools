# Tritic tools

Sitio estático de herramientas y recursos para impresión 3D, diseño y manufactura.
Publicado en <https://tools.tritic3d.com> con GitHub Pages.

- `site/` — contenido publicado (HTML, CSS, assets). `site/CNAME` define el dominio.
- `.github/workflows/pages.yml` — despliega `site/` en cada push a `main`.

Vista local: `cd site && python -m http.server 8000`
